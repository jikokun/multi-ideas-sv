11. Alerta Estelar Kick Nativa

Kick Pusher
Conexión: 100% Nativa KickCanal: @jikokunVariables: {user}, {meses}, {subs}

Opciones de Personalización

💡

Conexión 100% Nativa a Kick (Sin programas extra): Se conecta directamente a la nube de Kick Pusher y la API REST de Kick ingresando tu nombre de usuario. Diseño cósmico con píldora superior, rombo inferior, constelaciones curvas, estrellas flotantes y temas de color dinámicos según el tipo de evento (Followers, Subs, Gifts, Raids y Kicks).

Kick Dinámico 🚀
💡 Variables dinámicas de Kick: Usa {user} para el nombre, {meses} para meses de suscripción, {subs} para subs regaladas, {viewers} para raid y {kicks} para los Kicks. El número se actualizará automáticamente en vivo.
