Efecto Avioncito de Envío para WhatsApp ✈️

Haz clic en cualquiera de los botones para ver la animación de despegue y redirección

1. Estilo Tarjeta de Negocio

Diseño compacto con borde sutil. Al tocarlo, el icono de WhatsApp se transforma en un avión de papel que sale disparado en diagonal.

WhatsApp

2. Píldora 3D con Partículas

Botón prominente de contacto con gradiente esmeralda, chispas de propulsión y despegue enérgico.

3. Botón Flotante (FAB)

Ideal para el botón fijo en la esquina de la pantalla. Pulso de radar constante que dispara el avión al presionarlo.

Listo. Haz clic en cualquier botón de WhatsApp para probar el despegue.
delay: 450ms

📋 Cómo aplicarlo en tus botones de Sensun Shop (`.btn-wsp`)

/* 1. Modificación en tu función JS que maneja el clic */
document.querySelectorAll('.btn-wsp').forEach(btn => {
  btn.addEventListener('click', function(e) {
    e.preventDefault();
    const targetUrl = this.getAttribute('href');
    
    this.classList.add('is-flying');
    const textEl = this.querySelector('.btn-text') || this;
    const originalText = textEl.textContent;
    textEl.textContent = '¡Enviando…!';
    
    setTimeout(() => {
      window.open(targetUrl, '_blank', 'noopener,noreferrer');
      setTimeout(() => {
        this.classList.remove('is-flying');
        textEl.textContent = originalText;
      }, 1000);
    }, 450); // 450ms de vuelo antes de abrir WhatsApp
  });
});
